    How to join
    1. Ask whoever runs this dashboard to make you a login. Your username is your first name.
    2. Use Firefox. Download the newest .xpi file from the latest release and open it in Firefox to install the extension. It updates itself after that.
    3. The settings page opens. Click Allow access, sign in to leetcode.com in Firefox, and pick which sites to block.
    4. Under Practice with friends, enter your first name, your password and this page's address: . Click Sync now.
    5. Log in here with the same name and password.

    For hints, lessons and grading, the extension needs Claude: either Claude Code on your own computer (the bridge in the release, on your own Claude plan) or an API key. Everything else works without it.
