    How to join
    1. Use Firefox. Download the newest .xpi file from the latest release and open it in Firefox to install the extension. It updates itself after that.
    2. The settings page opens. Click Allow access, sign in to leetcode.com in Firefox, and pick which sites to block.
    3. Under Practice with friends, enter your first name and this page's address: . Click Sync now.
    4. Come back here and type the same first name.

    For hints, lessons and grading, the extension needs Claude: either Claude Code on your own computer (the bridge in the release, on your own Claude plan) or an API key. Everything else works without it.
