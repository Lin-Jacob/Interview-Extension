LeetCode Daily Lock

Sites stay blocked each day until today's task is done: a LeetCode problem, a SQL problem, a system design lesson and quiz, or a behavioral question, depending on the weekday. Sign in to leetcode.com in this browser so solves are detected automatically.

One more step

Firefox needs your OK for the extension to read your LeetCode progress and reach the Claude API.

Daily task by weekday Each day has one task. Sites unlock once it's done.

Week 1 is Easy only. Mediums come in gradually from week 2, and Hards only after day 42. Days count only when you hit your goal. Turning this off and on again restarts it.

Claude help

One-time setup for Claude Code
  1. Install Claude Code from claude.com/claude-code, run claude in a terminal once, and sign in with your Pro account.
  2. Unzip leetcode-daily-lock-bridge.zip and run node install.js inside it (needs Node.js 18 or newer).
  3. Restart Firefox, then click Test connection.
